# The Move-Out Edit

Mobile-friendly static GitHub Pages moving-sale catalogue with multiple photos, gallery arrows/swipes, item details, individual WhatsApp links, filter/search and item share links.

## Add or update items

Edit **products.js**. Duplicate the sample product object and set a unique id, title, category, asking price (numeric, in GBP), condition, originalPrice, originalUrl, retailerName, item-specific whatsappUrl, images, description, details, imperfections and collectionNotes. Put real photos inside assets/, update each image src path, and remove placeholder:true when appropriate. Photos and prices omitted remain clearly marked as placeholders.

Set status to available, reserved or sold. All items are collection from London E3 by arrangement. Shipping cost is the buyer's responsibility; local London drop-off may be possible by enquiry.

## Publish

In GitHub open Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save. Expected site address: https://thekmannn.github.io/MoveOutSale/ after deployment. Never put an exact home address, personal contact number, or other private details in this public repository.
