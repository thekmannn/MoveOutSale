# The Move-Out Edit

Mobile-friendly static GitHub Pages moving-out sale catalogue with multiple photos, item details, individual WhatsApp links, filter/search and item share links.

## Add or update items

Edit **products.js**. Duplicate the sample product object and set a unique id, title, category, asking price (numeric, in GBP), condition, originalPrice, originalUrl, retailerName, item-specific whatsappUrl, images, description, details, imperfections and collectionNotes. Put real photos inside assets/, and update each image src path.

Set status to available, reserved or sold.
